# .github

This repository holds the public profile of the [omicfinder](https://github.com/omicfinder) organization. GitHub displays `profile/README.md` on the organization page to all visitors. Members see the member-only profile from [omicfinder/.github-private](https://github.com/omicfinder/.github-private) instead, and can switch to the public view.

Community health files placed here (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, issue templates) apply by default to every organization repository that does not have its own.

## Contributing

Edit [`profile/README.md`](profile/README.md), for example to add a link to a public tool, then open a pull request.

This repository is public: do not put anything here that should stay within the team.
